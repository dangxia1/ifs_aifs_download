# 数据源与校验

## 数据源

截止2026-05-08测试结果（基于`ecmwf-opendata`库）：

| 源 | 可用性 | IFS 25MB | AIFS 24MB | 备注 |
|---|---|---|---|---|
| `ecmwf` | 好用 | 12-21s (1.3-2.2 MB/s) | 12-15s (1.5-2.0 MB/s) | 首选用源，仅保留~4天 |
| `azure` | 可用 | 90-114s (220-280 KB/s) | 74-334s (70-330 KB/s) | 有历史数据，挂VPN测 |
| `aws` | 不稳定 | - | - | 偶发503 SlowDown限流 |
| `google` | 不可用 | - | - | GCS不支持多字节范围请求 |

- **ecmwf**：仅保留~4天，速度快（1-2 MB/s）；404错误不重试直接跳过
- **azure**：历史数据窗口更长，适合补缺口（`dl_anytime.py`）；SAS token鉴权，速度~100-300 KB/s
- **aws**：偶发限流，可重试
- **google**：不支持`retrieve()`的多range请求，不可用
- 2026-05-12前后的数据使用不同的stream结构（库自动处理，无需手动干预）

### 跨源一致性

ecmwf与azure下载的同日期数据（2026-04-30）逐字节对比完全一致：40条消息、每条大小、文件总大小均相同。不同源只是传输通道不同，气象数据本身一致。

## GRIB文件校验

### 依赖

```
ecmwf-opendata
eccodes
```

### 预期消息数量

| 类型 | 参数数 | 层数 | 总消息数 |
|---|---|---|---|
| 单层(surface) | 4 | 1 | 4 |
| 气压层(pressure) | 4 | 9 | 36 |

### 校验脚本

```python
import eccodes

def verify_grib(path, expected_params):
    """校验GRIB文件，返回(实际变量, 缺失, 多余)。"""
    with open(path, "rb") as f:
        actual = []
        while True:
            msg_id = eccodes.codes_grib_new_from_file(f)
            if msg_id is None:
                break
            actual.append(eccodes.codes_get(msg_id, "shortName"))
            eccodes.codes_release(msg_id)
    missing = set(expected_params) - set(actual)
    extra = set(actual) - set(expected_params)
    return actual, missing, extra
```

### 文件大小参考

实际大小因日期和压缩率略有浮动：

| 模型 | 单层 (step=0) | 气压层 (step=0) | 全部 (step=0) |
|---|---|---|---|---|
| IFS | ~1.1 MB | ~24 MB | ~25 MB (40条) |
| AIFS | ~1.1 MB | ~23 MB | ~24 MB (40条) |

单文件实测 22.5~27 MB（step 越大文件越小）。

### 合并下载

**不能在一次`retrieve()`中混搭单层和气压层参数。** 指定`levelist`后单层变量会被静默丢弃。必须分两次调用再合并：

```python
from ecmwf.opendata import Client

client = Client(source="ecmwf")
tmp1, tmp2 = "tmp_single.grib2", "tmp_levels.grib2"

# 分别下载
client.retrieve(date=..., time=0, type="fc", step=0,
                param=["2t", "msl", "tp", "ssrd"], target=tmp1)
client.retrieve(date=..., time=0, type="fc", step=0,
                param=["q", "u", "v", "t"],
                levelist=[1000, 925, 850, 700, 500, 300, 250, 200, 50], target=tmp2)
# 合并
with open("merged.grib2", "wb") as out:
    for t in (tmp1, tmp2):
        with open(t, "rb") as f:
            out.write(f.read())
```
