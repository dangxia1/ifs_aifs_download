# IVT + AR 可视化升级计划

## 目标

对实时预报的 9 个文件，输出 3 区域 × 9 张图 = **27 张 PDF**，小时级更新。

## 输出结构 (变更)

```
ec_realtime/figures/
├── global/                  ← 全球 (Robinson)
│   ├── ifs/  (5 PDF)
│   └── aifs/ (4 PDF)
├── east_asia/               ← 东亚 (105-150°E, 10-50°N)
│   ├── ifs/
│   └── aifs/
└── north_china/             ← 华北 (113-120°E, 35-45°N)
    ├── ifs/
    └── aifs/
```

## 每张图内容

| 图层 | 数据源 | 样式 |
|------|--------|------|
| 底图 | Cartopy feature | 海洋深蓝 (`#1a3a5c`)，陆地绿/黄 (`#8fbc8f`/`#e8d5a0`) |
| IVT 羽流外等值线 | `_ivt.nc` `IVT` | alpha=0.3 |
| IVT 羽流内等值线 | `_ar.nc` `AR_plume` 掩膜后的 IVT | alpha=1 |
| AR 河轴 | `_ar.nc` `AR_axis` | 紫色细线 overlay |
| 标注 | 硬编码 | 右下角 "ARIA-Globe vn.17" |

## 需要改动的文件

### 1. `visualize_ivt.py` → 重写

- 移除全球 Robinson 旧逻辑
- 新函数 `visualize_one_region(nc_path, ar_nc_path, pdf_path, region)` 支持 3 区域
- 区域参数：
  - `global`: Robinson 投影
  - `east_asia`: PlateCarree, extent=[105,150,10,50]
  - `north_china`: PlateCarree, extent=[113,120,35,45]
- 华北区域标北京红星 `(116.4°E, 39.9°N)`

### 2. `dl_realtime.py` — 加 AR 检测调用

AR 检测需要从 `dl_lastmonth_cal_ivt/detect_ar.py` 移植或直接 import。需要确认阈值目录在 `dl_realtime` 也可访问。

### 3. 删除旧 `visualize_ivt.py` 逻辑

旧版 `visualize_all` 遍历 ivt/{subdir} 的逻辑需要改为按区域生成。
