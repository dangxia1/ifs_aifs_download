# ARFS 打包与分发指南

> 将实时项目封装为绿色包（只读展示模式），整包发送即可在任意电脑运行。
> 2026-08-06 起展示层为**静态 HTML**（viewer.html），不再依赖 Streamlit。

## 离线 Windows 版（推荐，2026-08-06）

对方电脑**无需安装 Python、无需联网**，解压后双击 `start.bat` 即用。
原理：Linux 服务器交叉打包 Windows 运行时：

- python.org 官方 Windows embeddable Python（自包含解释器，仅 stdlib，~10MB）
- 展示页 `viewer.html`（纯 HTML+CSS+JS，**零第三方依赖**）
- conda-forge `vc14_runtime` 包提供 VC 运行库 dll（vcruntime140/msvcp140，
  对方未装 VC redist 也能跑）

**打包（服务器，一次命令）**：

```bash
conda activate ifs_aifs
cd ~/ifs_aifs_download/dl_realtime
python make_green_win.py
# 输出: /shared_data/zongshen/ARFS_green_win.zip (~80MB, 旧 streamlit 版 ~250MB)
```

把 zip 发给 Windows 用户 → 解压 → 双击 `start.bat` → 浏览器自动打开
`http://localhost:8501/viewer.html`。

包结构：

```
ARFS_green_win/
├── runtime/            # embeddable Python + VC dll (仅 stdlib, 无第三方包)
├── docs/               # 背景图
├── China_provinces.shp / Continent.shp   # 中国立场边界 (备用)
├── data/               # ← http.server 服务根目录
│   ├── viewer.html     # 展示页 (与 figures/ 同级, 页内相对路径)
│   ├── run_time.json   # 起报时间 (时次按钮换算预报时间)
│   └── figures/        # 最新一期 75+1 张图
├── start.bat           # 一键启动 (runtime python -m http.server 8501)
└── 使用说明.txt
```

注意：

- 图是服务器上最新一期；数据更新 = 重新打包替换
- 不在包内放 `config_realtime.yaml`（否则 save_dir 指向服务器路径）
- 首次使用请先验证：Windows 解压 → start.bat → 页面正常
- `file://` 直接双击 `data/viewer.html` 也可看图/切换（仅起报时间退化为"未知"）

## 服务器网页部署（http.server，替代旧 streamlit）

```bash
cd ~/ifs_aifs_download/dl_realtime
# 1. 拉代码后把展示页拷到数据根
cp viewer.html /shared_data/zongshen/ec_realtime/

# 2. 起静态服务 (替换旧 streamlit 进程)
pkill -f "streamlit run"
pkill -f "http.server 8501"
nohup python -m http.server 8501 --directory /shared_data/zongshen/ec_realtime \
  > /shared_data/zongshen/ec_realtime/log/httpd.log 2>&1 &
# 浏览器: http://10.2.7.31:8501/viewer.html
```

## 注意事项

- **start.bat 必须全英文**：Windows cmd 用 ANSI/GBK 解析 .bat，UTF-8 中文会乱码导致命令行断裂（报 "不是内部或外部命令"）。当前已全英文，任何编码均兼容。
- **只读展示**：包内是预生成图，不含下载/计算代码，无法更新数据。如需更新，重新打包最新图即可。
- **数据大小**：75 张 PNG (~50MB) + 时序图，zip 后约 30MB。
- **时区**：标题时间为北京时间。
- **端口占用**：8501 被占时关闭占用程序或改端口（start.bat 与命令中同步修改）。
