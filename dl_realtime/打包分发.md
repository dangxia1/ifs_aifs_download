# ARFS 绿色包打包指南

> 将实时项目封装为绿色包（只读展示模式），整包发送即可在任意电脑运行。

## 包结构

```
ARFS_green/
├── app.py                    # Streamlit 界面 (只读展示)
├── start.bat                 # Windows 一键启动
├── start.sh                  # Linux/Mac 一键启动
├── requirements.txt          # 展示模式依赖 (仅 streamlit + pillow)
├── data/                     # 预生成数据 (见下)
│   └── figures/              # 75 张图 + 时序图
└── 使用说明.txt
```

## 打包步骤（在服务器上执行）

```bash
# 1. 建目录
mkdir -p /shared_data/zongshen/ARFS_green/data

# 2. 复制代码 (只读展示只需 app.py + docs 背景图)
cp /home/zongshen/ifs_aifs_download/dl_realtime/app.py /shared_data/zongshen/ARFS_green/
cp -r /home/zongshen/ifs_aifs_download/dl_realtime/docs /shared_data/zongshen/ARFS_green/
cp /home/zongshen/ifs_aifs_download/dl_realtime/start.bat /shared_data/zongshen/ARFS_green/
cp /home/zongshen/ifs_aifs_download/dl_realtime/start.sh /shared_data/zongshen/ARFS_green/

# 3. 复制生成的图 (当前最新一套)
cp -r /shared_data/zongshen/ec_realtime/figures/* /shared_data/zongshen/ARFS_green/data/figures/

# 4. 生成展示模式 requirements (只有 streamlit)
echo "streamlit" > /shared_data/zongshen/ARFS_green/requirements.txt
echo "pillow" >> /shared_data/zongshen/ARFS_green/requirements.txt

# 5. 写使用说明
cat > /shared_data/zongshen/ARFS_green/使用说明.txt <<'EOF'
ARFS 大气河短期预报支撑平台 — 使用说明

Windows: 双击 start.bat
Linux/Mac: ./start.sh

首次运行自动创建环境并安装依赖 (需联网)。
启动后浏览器自动打开 http://localhost:8501
EOF

# 6. 打包 zip
cd /shared_data/zongshen
zip -r ARFS_green.zip ARFS_green/
```

## 对方电脑要求

| 项 | 要求 |
|----|------|
| Python | 3.10+ (Windows 从 python.org 装, 勾选 Add to PATH) |
| 网络 | 首次运行需联网装依赖 (streamlit ~50MB) |
| 系统 | Windows / Linux / Mac 均可 |

## 注意事项

- **只读展示**：包内是预生成图，不含下载/计算代码，无法更新数据。如需更新，重新打包最新图即可。
- **数据大小**：75 张 PNG (~50MB) + 时序图，zip 后约 30MB。
- **时区**：标题时间为北京时间。

## 进阶：完整模式（对方电脑自己下载数据）

若需要对方能自动更新数据，打包整个 `dl_realtime/` 代码 + `requirements.txt`（全量依赖），按 README 部署（conda/miniforge + 阈值文件 + crontab）。此模式较重，默认不采用。
